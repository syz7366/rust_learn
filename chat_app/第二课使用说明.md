## 📖 核心知识点详解

### 1. 所有权系统（Ownership）

Rust 最核心的特性，三条规则：

1. **每个值都有一个所有者**
2. **同一时刻只能有一个所有者**
3. **所有者离开作用域，值被自动释放**

#### 示例：所有权转移（Move）

```rust
let s1 = String::from("hello");
let s2 = s1;  // s1 的所有权转移给 s2
// println!("{}", s1);  // ❌ 错误！s1 已失效
println!("{}", s2);  // ✅ 正确
```

#### 示例：借用（Borrowing）

```rust
let s1 = String::from("hello");
let len = calculate_length(&s1);  // 借用，不转移所有权
println!("{} 的长度是 {}", s1, len);  // ✅ s1 仍可用

fn calculate_length(s: &String) -> usize {
    s.len()
}
```

#### 示例：可变借用

```rust
let mut s = String::from("hello");
change(&mut s);  // 可变借用

fn change(s: &mut String) {
    s.push_str(", world");
}
```

**重要规则**：
- ✅ 可以有**多个不可变借用**
- ✅ 可以有**一个可变借用**
- ❌ **不能同时有可变和不可变借用**

### 2. 错误处理

Rust 没有异常（Exception），使用 `Result` 和 `Option`。

#### Option<T> - 可能不存在的值

```rust
enum Option<T> {
    Some(T),  // 有值
    None,     // 无值
}

let users = vec!["Alice", "Bob"];
match users.get(0) {
    Some(name) => println!("用户: {}", name),
    None => println!("没找到"),
}
```

#### Result<T, E> - 可能失败的操作

```rust
enum Result<T, E> {
    Ok(T),   // 成功
    Err(E),  // 失败
}

fn parse_port(s: &str) -> Result<u16, String> {
    match s.parse::<u16>() {
        Ok(port) => Ok(port),
        Err(_) => Err(String::from("解析失败")),
    }
}

// 使用
match parse_port("8080") {
    Ok(port) => println!("端口: {}", port),
    Err(e) => println!("错误: {}", e),
}
```

#### ? 操作符 - 简化错误传播

```rust
fn read_file() -> Result<String, std::io::Error> {
    let content = std::fs::read_to_string("file.txt")?;  // 失败时提前返回
    Ok(content)
}
```

### 3. TCP 服务器核心代码

```rust
use std::net::TcpListener;

fn start_server() -> std::io::Result<()> {
    // 绑定地址
    let listener = TcpListener::bind("127.0.0.1:8080")?;
    
    // 接受连接
    for stream in listener.incoming() {
        match stream {
            Ok(stream) => handle_client(stream)?,
            Err(e) => eprintln!("错误: {}", e),
        }
    }
    
    Ok(())
}
```

**关键点**：
- `TcpListener::bind()` 返回 `Result`
- `listener.incoming()` 是迭代器，产生 `Result<TcpStream>`
- `?` 操作符传播错误

## 💡 常见问题

### Q1: 为什么 Rust 需要所有权系统？

**A**: 为了在**编译时**保证内存安全，无需垃圾回收器（GC）：
- ✅ 无 GC 停顿
- ✅ 无内存泄漏
- ✅ 无数据竞争
- ✅ 零成本抽象

### Q2: 什么时候用 & 什么时候不用？

**A**: 
- 不想转移所有权 → 用 `&`（借用）
- 需要修改值 → 用 `&mut`
- 转移所有权给函数/变量 → 不加 `&`

### Q3: unwrap() 什么时候用？

**A**:
- ✅ 原型开发/快速测试
- ✅ 确定不会失败的情况
- ❌ 生产代码（应该用 `match` 或 `?`）

### Q4: 服务器只能接受一个客户端？

**A**: 是的！当前版本的服务器处理完一个客户端后会继续等待下一个，但**不能同时**处理多个客户端。这是为了循序渐进学习，下一课会添加多客户端支持（多线程）。
