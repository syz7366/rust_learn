## 📚 已学内容速查

### 第一课：基础语法

| 概念 | 语法 | 示例 |
|------|------|------|
| 不可变变量 | `let` | `let x = 5;` |
| 可变变量 | `let mut` | `let mut y = 10;` |
| 函数 | `fn name(param: Type) -> ReturnType` | `fn add(a: i32, b: i32) -> i32` |
| 字符串 | `String` / `&str` | `String::from("hi")` / `"hi"` |
| 数组 | `[T; N]` | `[1, 2, 3]` |
| 元组 | `(T1, T2, ...)` | `("Alice", 25)` |

### 第二课：核心特性

#### 所有权规则
```rust
// 1. 转移（Move）
let s1 = String::from("hello");
let s2 = s1;  // s1 失效

// 2. 借用（Borrow）
let s1 = String::from("hello");
let len = calc(&s1);  // s1 仍有效

// 3. 可变借用
let mut s = String::from("hello");
change(&mut s);
```

#### 借用规则记忆口诀
> **要么多读，要么一写**
> - ✅ 多个 `&T`（不可变借用）
> - ✅ 一个 `&mut T`（可变借用）
> - ❌ 不能混用

#### 错误处理速查

| 类型 | 用途 | 示例 |
|------|------|------|
| `Option<T>` | 可能不存在 | `Some(value)` / `None` |
| `Result<T, E>` | 可能失败 | `Ok(value)` / `Err(error)` |
| `?` | 错误传播 | `let x = func()?;` |
| `unwrap()` | 快速取值（危险）| `let x = opt.unwrap();` |
| `match` | 模式匹配 | `match x { ... }` |
| `if let` | 简化匹配 | `if let Some(v) = x { ... }` |

## 💡 Rust 特色概念

### 1. 宏（Macro）
带 `!` 的是宏，不是函数：
- `println!()` - 打印输出
- `vec![]` - 创建向量
- `format!()` - 格式化字符串

### 2. Trait（特征）
类似其他语言的接口：
```rust
// Read trait 提供 read() 方法
// Write trait 提供 write() 方法
use std::io::{Read, Write};
```

### 3. 生命周期
