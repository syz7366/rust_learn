#### 2. 变量和不可变性
- **默认不可变**：Rust 变量默认是 immutable
  ```rust
  let x = 5;          // 不可变
  let mut y = 10;     // 可变（需要 mut 关键字）
  ```
- **变量遮蔽（Shadowing）**：可以重新声明同名变量，甚至改变类型
  ```rust
  let msg = "Hello";
  let msg = msg.len();  // 类型从 &str 变为 usize
  ```

#### 3. 数据类型
- **标量类型**：
  - 整数：`i8, i16, i32, i64, i128`（有符号）和 `u8, u16, u32, u64, u128`（无符号）
  - 浮点数：`f32, f64`
  - 布尔值：`bool`
  - 字符：`char`（可以是 Unicode）
  
- **复合类型**：
  - 元组：`(T1, T2, T3)` - 可以包含不同类型
  - 数组：`[T; N]` - 固定长度，相同类型

- **字符串类型**：
  - `String`：可变，拥有所有权，存储在堆上
  - `&str`：不可变，字符串切片，通常是借用

#### 4. 函数
```rust
fn function_name(param: Type) -> ReturnType {
    // 函数体
    return_value  // 不加分号表示返回
}
```
- 参数必须声明类型
- 使用 `->` 指定返回类型
- 最后一个表达式（不加分号）自动作为返回值

## ✅ 第二课：TCP 服务器与 Rust 核心特性

**完成时间**：2025-10-27  
**学习目标**：掌握所有权系统、错误处理，实现 TCP 服务器

### 📚 知识点总结

#### 1. 所有权系统（Ownership）⭐⭐⭐⭐⭐

**Rust 最核心的特性！**三条规则：

1. **每个值都有一个所有者**
2. **值在任一时刻只能有一个所有者**
3. **当所有者离开作用域，值被自动丢弃（drop）**

##### 所有权转移（Move）
```rust
let s1 = String::from("hello");
let s2 = s1;  // s1 的所有权转移给 s2
// println!("{}", s1);  // ❌ 错误！s1 已失效
```

##### 借用（Borrowing）
```rust
let s1 = String::from("hello");
let len = calculate_length(&s1);  // & 表示借用，不转移所有权
println!("{}", s1);  // ✅ s1 仍可用

fn calculate_length(s: &String) -> usize {
    s.len()
}
```

##### 可变借用
```rust
let mut s = String::from("hello");
change(&mut s);  // &mut 表示可变借用

fn change(s: &mut String) {
    s.push_str(", world");
}
```

##### 借用规则 ⭐
- ✅ 可以有**多个不可变借用** `&T`
- ✅ 可以有**一个可变借用** `&mut T`
- ❌ **不能同时有可变和不可变借用**

##### 为什么需要所有权？
- ✅ 编译时保证内存安全
- ✅ 无需垃圾回收器（GC）
- ✅ 无数据竞争
- ✅ 零成本抽象

#### 2. 错误处理（Error Handling）⭐⭐⭐⭐

Rust **没有异常机制**，使用 `Result` 和 `Option` 类型。

##### Option<T> - 表示可能不存在的值
```rust
enum Option<T> {
    Some(T),  // 有值
    None,     // 无值
}

// 使用示例
let users = vec!["Alice", "Bob"];
match users.get(0) {
    Some(name) => println!("用户: {}", name),
    None => println!("没找到"),
}
```

##### Result<T, E> - 表示可能失败的操作
```rust
enum Result<T, E> {
    Ok(T),   // 成功，包含返回值
    Err(E),  // 失败，包含错误信息
}

// 使用示例
fn parse_port(s: &str) -> Result<u16, String> {
    match s.parse::<u16>() {
        Ok(port) => Ok(port),
        Err(_) => Err(String::from("解析失败")),
    }
}

match parse_port("8080") {
    Ok(port) => println!("端口: {}", port),
    Err(e) => println!("错误: {}", e),
}
```

##### ? 操作符 - 错误传播
```rust
fn connect() -> Result<String, String> {
    let port = parse_port("8080")?;  // 失败时自动返回 Err
    Ok(format!("连接到 {}", port))
}
```

##### 快捷方法（谨慎使用）
- `unwrap()`: 失败时 panic，适合原型开发
- `expect("msg")`: 同 unwrap，但有自定义错误消息
- 生产环境应使用 `match` 或 `?`

#### 3. 模式匹配（Pattern Matching）

##### match 表达式
```rust
match value {
    pattern1 => expression1,
    pattern2 => expression2,
    _ => default_expression,  // _ 匹配其他所有情况
}
```

##### if let - 简化的 match
```rust
if let Some(user) = users.get(0) {
    println!("用户: {}", user);
}

// 等价于
match users.get(0) {
    Some(user) => println!("用户: {}", user),
    None => {}
}
```

#### 4. TCP 服务器实现

##### 核心代码结构
```rust
use std::net::{TcpListener, TcpStream};
use std::io::{Read, Write};

fn start_server() -> std::io::Result<()> {
    // 1. 绑定地址
    let listener = TcpListener::bind("127.0.0.1:8080")?;
    
    // 2. 监听连接
    for stream in listener.incoming() {
        match stream {
            Ok(stream) => handle_client(stream)?,
            Err(e) => eprintln!("错误: {}", e),
        }
    }
    
    Ok(())
}

fn handle_client(mut stream: TcpStream) -> std::io::Result<()> {
    // 3. 读写数据
    let mut buffer = [0; 512];
    
    loop {
        match stream.read(&mut buffer) {
            Ok(0) => break,  // 连接关闭
            Ok(n) => {
                let msg = String::from_utf8_lossy(&buffer[..n]);
                stream.write_all(msg.as_bytes())?;
            }
            Err(e) => return Err(e),
        }
    }
    
    Ok(())
}
```

##### 关键概念
- `TcpListener::bind()`: 绑定地址并监听
- `listener.incoming()`: 迭代器，产生客户端连接
- `TcpStream`: 代表一个 TCP 连接
- `Read` trait: 提供 `read()` 方法
- `Write` trait: 提供 `write_all()` 方法
